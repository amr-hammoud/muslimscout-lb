# Muslim Scout Leaders in Lebanon

A static, bilingual site for Muslim Scout leaders in Lebanon, with pages for each section (cubs, scouts, advanced, rovers), news and the Sustainable Development Goals. Live demo: [muslimscout.amrhammoud.com](https://muslimscout.amrhammoud.com).

## Deploy

```bash
npx wrangler deploy
```

## Stack

- HTML, CSS and JavaScript
- Cloudflare Workers static assets
